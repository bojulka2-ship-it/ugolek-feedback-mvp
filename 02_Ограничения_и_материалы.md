# Ограничения и доступные материалы

## Срок и формат пилота

- первый работающий вариант нужен за один учебный спринт;
- демонстрация проходит локально в браузере (localhost, запуск `node server.js`);
- пилот проверяют 2-4 ответа;
- интерфейс должен работать на телефоне и компьютере.

## Технические ограничения MVP

- без платного хостинга (только localhost);
- централизованный сбор отзывов требует общего хранилища: для MVP допускается минимальный локальный сервер на Node.js (только стандартная библиотека, без npm/внешних пакетов) с файлом `reviews.json`; без СУБД и внешних сервисов;
- без авторизации;
- без реальной отправки писем и сообщений;
- без интеграции с CRM;
- без загрузки файлов;
- без генерации PDF;
- без внешних AI API;
- только HTML, CSS и JavaScript и минимальный Node.js-сервер (стандартная библиотека) — выбор обоснован требованием централизованного сбора отзывов;

## Данные и безопасность

- использовать только вымышленные данные;
- не добавлять в репозиторий токены, пароли или API-ключи;
- не запрашивать паспортные, платежные и иные чувствительные данные.

## Доступные материалы

- цвет акцента - тёплые, «уютные» цвета: Оранжевый
для выделения кнопок призыва к действию; Коричневый -
для элементов, связанных с брендом: иконки меню, фон кнопок, элементы логотипа; Зелёный.
- логотипа в пригодном формате пока нет — в MVP использовать текст `Кофейня Уголёк`;
- фотографии интерьеров не предоставлены;
- юридические тексты и политика обработки персональных данных не согласованы, поэтому публичный запуск не входит в MVP.

## Браузеры

- актуальные версии Chrome, Edge и Safari;
- минимальная ширина экрана — 360 пикселей.
