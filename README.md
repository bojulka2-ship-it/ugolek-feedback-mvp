## 1. Назначение и возможности сервиса

Сервис собирает отзывы гостей кофейни в одном месте вместо бумажных карточек и комментариев в соцсетях. Гость оставляет оценку и текст отзыва через простую страницу, владелец видит все отзывы в общем списке.

Что умеет сервис:

- **Оценка визита от 1 до 5 звёзд** — кликом или с клавиатуры; выбранное количество подсвечивается.
- **Поле «Что понравилось из меню» и комментарий** — необязательные поля с ограничениями по длине.
- **Общий список отзывов** — новые отзывы сверху, сохраняются между перезапусками сервера.
- **Защита от мусорных отзывов** — сервер отклоняет наборы повторяющихся символов и текст, набранный не в той раскладке; браузер дополнительно подсказывает при вводе.
- **Защита от перегрузки** — не более 10 отзывов в минуту с одного адреса (ответ `429`).
- **Адаптивный интерфейс** — корректно отображается от ширины экрана 360 px (телефоны).
- **Работа без внешних сервисов** — нет внешних запросов, аналитики и npm-зависимостей.

## 2. Как выглядит интерфейс

Страница — одна и та же и для гостя, и для владельца (форма + список отзывов):

- сверху — форма: ряд из 5 звёзд, поле «Что понравилось из меню», поле «Комментарий» и кнопка «Отправить»;
- при выборе звёзды заполняются оранжевым; при ошибках под формой появляется красное пояснение (например, «похоже на текст не в той раскладке»);
- ниже — список отзывов: звезды оценки, текст меню/комментария и дата; новые отзывы сверху;
- при пустом списке показывается приглашение «Пока нет отзывов».

Скриншот в репозиторий не включён: на нём были бы реальные отзывы гостей — это персональные данные.

## 3. Системные требования

- **Node.js** версии 18 и выше (разработка и проверка на версии 24). Скачать: <https://nodejs.org> — установите LTS-версию.
- ОС: Windows, macOS или Linux — сервер не зависит от платформы.
- Браузер для работы со страницей: актуальная версия Chrome, Edge, Firefox или Safari. Поддержка JavaScript обязательна.
- Отдельных пакетов/баз данных не требуется.

Проверить установленный Node.js:

```bash
node --version
```

## 4. Установка с чистого компьютера

Шаг 1. Установите Node.js (смотрите раздел «Системные требования»).

Шаг 2. Скопируйте проект. Два способа — выберите один.

Способ A — через Git (рекомендуется, удобно для обновлений):

```bash
git clone https://gitverse.ru/JuBo/Cafe_Ugolek_clients_anketa.git
```

Способ B — без Git (загрузите архив):

1. Откройте страницу проекта в GitVerse;
2. нажмите кнопку «Скачать» / «Download» и выберите «Архив» (ZIP);
3. распакуйте архив в нужную папку.

После установки перейдите в папку проекта:

```bash
cd Cafe_Ugolek_clients_anketa
```

## 5. Виртуальное окружение

Для этого проекта виртуальное окружение **не требуется**. Сервис работает только на встроенных средствах Node.js: в репозитории нет ни одного npm-пакета, поэтому устанавливать и «изолировать» зависимости нечего. Файл `package.json` отсутствует намеренно — это упрощает установку и исключает проблемы со сборкой.

## 6. Запуск

Из папки проекта выполните:

```bash
node server.js
```

В консоли появится строка вида `Кофейня Уголёк: http://localhost:<порт>`. Откройте этот адрес в браузере.

Чтобы остановить сервер — нажмите в терминале `Ctrl+C`.

При первом отзыве сервер автоматически создаст файл `reviews.json` — специально создавать его не нужно.

> Настройка порта и сетевого адреса — в разделе «Переменные окружения».

## 8. Проверка работоспособности

Шаг 1. Запустите сервер, как описано в разделе «Запуск».

Шаг 2. Откройте в браузере адрес из консоли — должна загрузиться страница с формой отзыва.

Шаг 3. Отправьте отзыв: выберите звезды, заполните поля и нажмите «Отправить». Отзыв должен появиться в списке.

Шаг 4. Быстрая проверка API из консоли (команды копируемые):

Проверить, что страница отдаётся (ожидается `200`):

```bash
curl -i http://localhost:3000
```

Проверить список отзывов (ожидается `200` и JSON):

```bash
curl -i http://localhost:3000/api/reviews
```

Отправить корректный отзыв (ожидается `201`):

```bash
curl -i -X POST http://localhost:3000/api/reviews -H "Content-Type: application/json" -d "{\"rating\":5,\"menu\":\"latte\",\"comment\":\"ok\"}"
```

Отправить недопустимый отзыв, оценка вне диапазона (ожидается `400`):

```bash
curl -i -X POST http://localhost:3000/api/reviews -H "Content-Type: application/json" -d "{\"rating\":0}"
```

> Адрес `http://localhost:3000` в примерах соответствует настройкам по умолчанию. Если порт изменён — замените номер в командах.

## 9. Переменные окружения

Все настройки задаются переменными окружения — значения в коде не хранятся. Ниже — только имена и назначение, без значений:

| Имя | Назначение |
|---|---|
| `PORT` | TCP-порт, на котором слушает сервер |
| `HOST` | Сетевой адрес, к которому привязывается сервер |
| `RATE_LIMIT_WINDOW_MS` | Длина окна ограничения частоты отправки отзывов (в миллисекундах) |

Задать переменную перед запуском (примеры применены с подстановкой значения на месте):

Windows (PowerShell):

```powershell
$env:PORT = '<порт>'
node server.js
```

Windows (CMD):

```cmd
set PORT=<порт>
node server.js
```

Linux и macOS:

```bash
PORT=<порт> node server.js
```

## 10. Деплой (размещение на сервере)

Сервис не требует базы данных и npm-зависимостей, поэтому деплой прост.

Минимальный сценарий на Linux-сервере:

1. Установите Node.js (LTS) на сервер.
2. Скопируйте проект (Git или архив — раздел «Установка»).
3. Задайте переменные окружения (раздел «Переменные окружения»): укажите `PORT` и `HOST`, если нужен доступ с других устройств/из интернета.
4. Запустите и настройте автоматический запуск, например через `systemd` (пример unit-файла — ниже) или менеджер процессов.

Пример unit-файла для `systemd` (`/etc/systemd/system/ugolek.service`):

```ini
[Unit]
Description=Ugolek reviews service
After=network.target

[Service]
WorkingDirectory=/opt/ugolek
ExecStart=/usr/bin/node server.js
Restart=on-failure
Environment=PORT=<порт>
Environment=HOST=<адрес>

[Install]
WantedBy=multi-user.target
```

Активировать:

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now ugolek
```

Запуск как служба Windows: используйте планировщик задач или утилиту NSSM (`nssm install ugolek node server.js` с нужным рабочим каталогом).

Решение по адресации, файрволу и (при необходимости) reverse-proxy принимается на стороне вашего хостинга/инфраструктуры — в коде проекта этих настроек нет.

## 11. Обновление

1. Остановите сервер.
2. Убедитесь, что папка проекта — это клон репозитория (вариант установки «через Git»).

```bash
git pull
```

3. При необходимости замените файл `reviews.json` на тот, что был у вас раньше (см. «Резервное копирование»).
4. Проверьте работоспособность (раздел 8) и запустите сервер вновь.

Если проект был установлен архивом — замените код вручную, сохранив файл `reviews.json`.

## 12. Резервное копирование

Все данные — один файл `reviews.json` в папке проекта. Чтобы сделать резервную копию, достаточно скопировать его в надёжное место:

```bash
cp reviews.json reviews-backup-<дата>.json
```

Периодически копируйте этот файл на отдельный носитель или в облако. Восстановление — обратное копирование файла на место. Файл `.gitignore` исключает `reviews.json` из git намеренно: в репозиторий не должны попасть персональные данные гостей.

## 13. Известные ограничения

- **Одно хранилище** — все отзывы хранятся в одном локальном файле на сервере; это не полноценная СУБД.
- **Нет личного кабинета и модерации** — любой посетитель страницы может оставить отзыв; удаление/редактирование отзывов в интерфейсе не предусмотрено (можно чистить файл `reviews.json` вручную).
- **Нет авторизации и шифрования на уровне приложения** — защиту транспортного слоя (HTTPS) обеспечивает внешний reverse-proxy, если требуется.
- **Нет уведомлений** (почта, push, мессенджеры) — отзывы только копятся в общем списке.
- **Лимит частоты** применяется к каждому сетевому адресу отдельно — под общим NAT-адресом лимит общий.
- **Отзывы не синхронизируются между несколькими экземплярами сервера** — это однопроцессное приложение.

Полный перечень ограничений и принятых решений — в `02_Ограничения_и_материалы.md` и `AUDIT_REPORT.md`.

## 14. Если что-то не работает

**Страница не открывается.**
Проверьте: сервер запущен (`node server.js`), в консоли нет ошибок, порт не занят другой программой (смените `PORT`), нет блокировки фаерволом.

**Страница открывается, но отзыв не отправляется.**
Обновите страницу с очисткой кэша комбинацией `Ctrl+F5`, проверьте, что в браузере включён JavaScript, и что форма не останавливает вас подсказками (читайте текст под формой).

**Отзыв не появляется в списке.**
Проверьте ответ сервера: `429` — слишком много отправок за последнюю минуту, `400` — текст отклонён (повторяющиеся символы/не та раскладка/слишком длинное поле), `413` — слишком большой текст. При ошибке завершите проверку и повторите.

**При выборе звёзд не видно, сколько выбрано.**
Обновите страницу (`Ctrl+F5`) и используйте актуальный браузер.

**После переезда на другой компьютер отзывы «пропали».**
Файл `reviews.json` не хранится в репозитории намеренно. Перенесите его вместе с проектом или восстановите из резервной копии — при отсутствии файла сервер начнёт с пустого списка.

**Сервер не запускается на Windows: «не является внутренней или внешней командой».**
Node.js не установлен или не добавлен в `PATH`. Установите Node.js LTS с <https://nodejs.org> и перезапустите терминал.

**В консольных тестах кириллица выглядит «кракозябрами».**
Это кодировка окна консоли Windows, не ошибка сервиса. Используйте для тестов примеры с латинскими символами (раздел 8) или проверяйте через страницу в браузере.
